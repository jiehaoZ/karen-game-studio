Game Studio

做游戏素材时反复要用的小工具，一件一件挂在这块板上。

每一件都在你自己的浏览器里跑完：不上传、不联网、不需要装环境。 双击就能用，关掉就没了。

工具 2 件可用

  • Canvas Aligner 可用 画布对齐 n 张图叠在同一个画布上，手动缩放到主体大小一致，一键导出 ZIP。 对着参考框调，肉眼确认。 图像 批量导出 离线 打开
  • Matte 可用 纯色背景抠图 黑底、白底、绿幕一键转透明。用成像方程反解，头发和柔边不会被切平。 复杂背景可选装 AI 模型。 图像 透明通道 离线 打开
  • 空位

为什么都在本地跑

素材是没发布的东西。传到别人服务器上处理，就等于发布了一次。 这里的工具全部在浏览器内完成计算，文件从头到尾没离开过这台机器。

怎么加新工具

每个工具是一个独立目录，自带 index.html，双击即可运行， 彼此之间没有依赖。往板上挂一件，就是新建一个目录。

Game Studio 本地优先 无构建步骤 无外部请求
